## DMIT VPS 有哪些限制需要注意？

購買海外 VPS 前，有幾點容易被忽略。

### 1. 流量與頻寬不是永久無限制

DMIT 不同產品線提供不同流量限制和端口能力，例如部分 Tier 1 套餐標示 Max IN/OUT 流量，而其他產品可能使用固定流量配置。:chatgpt-content-reference{index="9"}

如果部署：

- 影音服務
- 大文件下載
- 高流量網站

需要提前確認流量政策。

### 2. IP 資源可能存在地區限制

部分 Tier 1 產品頁面標註，分配 IP 並不保證所有國家或地區都可用。:chatgpt-content-reference{index="10"}

如果你的服務依賴特定 IP 地區或信譽，需要先確認。

### 3. 不同系列價格差距可能很大

同樣是 VPS，Premium、Eyeball、Tier 1 等系列定位不同。

不要只比較：

「4 核 CPU + 4GB RAM 哪家便宜」

更應比較：

「這個配置所在節點和網路是否符合我的使用者位置」。
